        Tips & hacks
        
Habits that change what comes back

      

      See the tutorials
    

    


    

      
Framing
Give the model a role before the task — “act as a line editor” changes the output more than any adjective will.

      
Scope
Break a large request into three small ones. Long single prompts hide the step where things went wrong.

      
Reuse
Save the prompts that worked. A personal template file beats re-typing from memory every time.

      
Verification
Fact-check anything you’ll publish or send. Ask for sources, then open them — confident wording is not evidence.

      
Iteration
Refine in follow-ups instead of starting a fresh chat. The context you built is usually the valuable part.

      
Chaining
Use one tool for research, another for drafting, a third for visuals. Most good workflows are hand-offs.
